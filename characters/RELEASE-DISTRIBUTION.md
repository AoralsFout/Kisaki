# 正式角色包分发登记

`release-allowlist.json` 是正式发布时的分发清单：只要角色 `id` 进入清单，就会被打包进正式角色包随版本分发，无需再提供许可或授权材料（无许可门禁）。

清单中每个条目只需提供 `id`：

1. `id` 对应 `characters/<id>/character.json`，打包脚本会校验该目录存在。

示例结构：

```json
{
  "characters": [
    { "id": "official_character" }
  ]
}
```

清单只负责记录哪些角色参与正式分发；角色作品的版权与许可责任由各角色作者/提供方自行承担。请勿将 Live2D 官方样例、未经授权的游戏或虚拟歌手角色、仅允许个人使用的模型或来源不明的立绘加入正式角色包。

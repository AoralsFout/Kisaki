# Kisaki 正式版发布基线

最后更新：2026-08-27

## 首发范围

| 渠道 | 平台 | 架构 | 支持状态 |
|---|---|---|---|
| Stable | Windows 10/11 | x86_64 | 正式支持 |
| Preview | macOS 11+ | Apple Silicon (aarch64) | 预览支持 |
| Preview | Ubuntu 22.04 及兼容发行版 | x86_64 | 预览支持；推荐 X11 |

首版暂不承诺 Windows ARM、Intel Mac、Linux ARM。Wayland 下鼠标穿透受协议限制，属于已知限制。

现有应用标识 `com.kisaki.app` 以 `.app` 结尾，Tauri 会对 macOS 给出兼容性警告。为避免直接更名造成旧版用户数据目录变化，本版保留该标识；后续只有在完成数据与密钥迁移并验证旧版升级后才能更名。

## v1 功能冻结

正式版范围包括：AI 对话、会话持久化、角色导入/编辑/导出、Live2D、可选 TTS、联网搜索、文件工具、托盘、单实例、开机自启、全局快捷键、通知和自动更新。

AI shell 命令执行不属于正式版能力。release 构建由前端隐藏并由 Rust 后端拒绝；仅 debug 或显式启用 `experimental-command` feature 的内部构建可用。

## 阻断级验收场景

1. 干净系统首次安装并启动，无崩溃或空白窗口。
2. 完成 API 配置、导入官方角色并成功进行一次对话。
3. 重启后会话、角色、窗口状态与密钥仍可用。
4. 从旧版下载安装更新、自动重启并显示新版本号。
5. 更新失败不会破坏当前安装或用户数据。
6. 开机自启、Alt+K、托盘退出、通知、透明窗口和鼠标穿透可用。
7. 清除本地数据会删除会话、角色、设置及三个系统密钥链条目。
8. 非开发构建中 Dev 面板与 shell 命令均不可用。

## 发布顺序

1. 完成功能、安全、数据与发布流水线闭环。
2. 生成未签名 RC，完成平台验收和灰度。
3. 冻结提交和版本。
4. 最后接入系统代码签名、公证与正式 updater 密钥。
5. 对签名后的最终二进制重新执行安装、升级和病毒扫描验收，再发布 Stable。

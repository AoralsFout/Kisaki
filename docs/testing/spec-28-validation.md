## 调整前口径

2026-09-23 的覆盖率配置使用 V8 provider，`include` 仅匹配源 `.ts` 文件，并在 `exclude` 中排除全部 `.vue` 文件。因此旧覆盖率数字不包含 Vue 单文件组件。仓库尚未直接声明 V8 覆盖率支持包，也没有独立的覆盖率命令。

工具栏透明度仍有一条读取组件源码并匹配模板文本的测试；滚动几何、角色悬浮滚轮和可编辑表单已有部分数值规则及组件测试。本次改动在这些现有测试上补缺口，不把旧口径与新口径的百分比直接比较。

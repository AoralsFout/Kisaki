# UI/UX 优化方案与分阶段执行记录

## 目标与审查依据

围绕桌宠陪伴、AI 对话、角色管理三个核心场景，保护用户操作成果，统一 UI 风格，改善内容布局和可访问性。
初始审查基于 Vue 组件、状态管理和窗口配置源码；桌面视觉、透明背景、系统缩放与原生窗口行为仍需实机验收。

## 执行约定

- 每阶段独立实施、验证并交用户审查。未经用户明确审查通过，不提交 Git、不进入下一阶段。
- 收到通过意见后，更新本记录，提交该阶段相关文件，再进入下一阶段；不自动推送远端。
- 审查要求修改时，继续在当前阶段修正和复验。
- 提交仅包含本任务变更；发现用户已有改动时保留，不覆盖。
- 每阶段交付列出变更、验证结果、限制和人工验收步骤。

## 阶段 1：输入安全与会话草稿

状态：用户已审查通过（2026-09-05），准予提交并进入阶段 2。

任务：
- 关闭输入框只隐藏，保留文字和图片。
- 按会话隔离内存草稿，切换回来恢复；发送后清理当前草稿。
- 输入法组合输入和选词 Enter 不发送，保留普通 Enter 发送与 Shift+Enter 换行。
- 异步图片读取结果归属原会话，避免切换会话导致附件串入。

验收：关闭重开、A/B 会话往返、文字与图片发送、中文选词、读图中切换会话均符合上述行为。
边界：本阶段不做重启后草稿恢复；发送仍沿用现有 send 事件契约，网络失败恢复与父组件拒绝发送时的草稿保护在阶段 2 处理。

## 阶段 2：删除、保存与失败恢复

状态：待阶段 1 审查并提交后开始。

任务：
- 删除会话、清空历史前明确显示影响；若提供撤销，延迟清理文件检查点。
- 统一未保存状态，覆盖切设置标签、角色编辑返回、关闭窗口，提供保存并离开、放弃更改、继续编辑。
- 配置保存增加进行中、成功、失败反馈，失败保留输入。
- 明确发送接受状态；父组件拒绝发送不丢草稿，网络失败可重试或恢复输入。
- 评估草稿持久化与附件容量、删除会话后的草稿清理。

验收：取消删除不改变数据；未保存更改在所有退出路径均受保护；保存和发送失败可恢复。

## 阶段 3：首次引导与设置导航

状态：待前阶段审查并提交。

任务：
- 未完成配置时主按钮为继续配置，稍后不等于完成，保留可恢复的配置待办。
- 添加角色、配置 AI 等入口可定位到已有设置窗口的正确标签。
- 区分信息已填写、已保存、连接测试通过，不以字段有效冒充连接成功。
- 设置按使用体验（通用、角色、语音）、连接与能力（AI、搜索、权限）、维护与帮助（隐私、诊断、关于）组织。

验收：零角色首次启动可以完整走通；已有设置窗口时导航准确；状态文案与真实结果一致。

## 阶段 4：设计变量与共享组件

状态：待前阶段审查并提交。

任务：
- 延续品牌蓝 #4A7AFF 和深靛背景，统一背景、面板、浮层、边框及语义状态颜色。
- 统一主按钮实色、次按钮描边或浅底、危险按钮语义；胶囊形主要用于标签。
- 建议圆角：控件 8px、卡片 12px、浮层 16px；间距采用 4px 基础刻度。
- 建议字号：正文 14px、辅助 12px、标题 20px；等宽字体仅用于路径、命令等内容。
- 提取按钮、表单项、弹窗、提示和保存栏共享组件，替换分散硬编码。
- 桌宠浮层适度透明，长文本和设置采用稳定底色；浅色气泡保留为明确组件变体。

验收：代表页面主次操作、圆角、间距、字号和状态一致；浅色和复杂壁纸下仍可读。

## 阶段 5：聊天与角色编辑布局

状态：待前阶段审查并提交。

任务：
- 陪伴状态收敛为聊天、换角色、更多；语音、穿透、设置进入更多，日志进入诊断。
- 对话状态形成会话标题、消息列表、输入框连续面板，减少历史与输入往返切换。
- 气泡承载短回复，长回复可展开；生成中允许阅读历史，限制改变上下文的操作。
- 工具进度和确认就近展示，停止按钮位置稳定。
- 历史消息保存角色身份快照；旧数据提供兼容回退。
- 角色编辑按基本信息、人设、外观与动作、语音组织，顶部固定名称和保存，右侧预览可收起。
- 改善窄窗口、长路径、多图片和长回复布局，避免固定预览宽度挤压编辑区。

验收：日常聊天、会话切换、工具执行和编辑角色各流程连续；小窗口无关键操作裁切。

## 阶段 6：可访问性与整体实机验收

状态：待前阶段审查并提交。

任务：
- 聊天正文、路径、错误信息可选择复制，长回复支持适当内容呈现和图片查看。
- 可点击卡片、会话项支持键盘；弹窗有语义、初始焦点、焦点限制、Esc 和返回焦点。
- 提示支持键盘聚焦，开关表达明确状态，统一可见焦点。
- 提高低对比小字可读性，尊重减少动画偏好。
- 验证首次配置、连续聊天、切换会话、编辑退出四条完整流程。
- 实机覆盖系统 100%/150% 缩放、不同窗口尺寸、不同桌面背景及支持的语言。

验收：关键流程可用键盘完成，状态和错误可理解，高缩放不遮挡内容，原生穿透/焦点行为正确。

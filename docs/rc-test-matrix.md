## RC 观察期

- 观察 7–14 天，记录活跃测试人数、启动次数、更新成功率和崩溃/卡死报告。
- Blocker 或 Critical 必须归零；High 必须修复或有负责人、规避方案和明确期限。
- 修复任何安装、更新、数据迁移或密钥问题后，重新执行 RC-01、RC-05、RC-06、RC-07、RC-08、RC-09。
- 观察期结束后冻结提交；系统代码签名、公证和正式 updater 密钥在最后阶段接入。
